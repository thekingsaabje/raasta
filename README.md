# Raasta (راستہ) 🎓🌍

**Raasta** ("The Path") is an open-source scholarship discovery, eligibility-matching, and application tracking platform built for students pursuing fully funded international degrees.

## Why Raasta Exists
Applying for global scholarships shouldn't require paying thousands of dollars to private study-abroad consultants. Information around university funding, APS certifications, language requirements, and document checklists is fragmented across hundreds of outdated portals. 

Raasta brings transparency to the process by aggregating, structuring, and simplifying global scholarship opportunities in one open platform.

## Core Features
- **Structured Scholarship Database:** Clear breakdowns of funding coverage, deadlines, and exact eligibility criteria.
- **Eligibility & Requirement Tracking:** Step-by-step guidance for complex regional requirements (APS, language certificates, research statements, and visa documentation).
- **AI-Assisted Data Pipeline:** Powered by custom Claude Code workflows and MCP scraping tools to turn messy university admission pages into clean, searchable student data.

## Tech Stack
- **Frontend / App:** Modern web stack (TypeScript / React)
- **Data & Automation:** Claude Code Agent Skills & Model Context Protocol (MCP) scrapers
